# Assets für wordpress.org

Dateien in diesem Ordner landen beim Release im SVN-Ordner `assets/` (nicht im Plugin selbst):

| Datei | Größe | Zweck |
|---|---|---|
| `icon-256x256.png` (+ `icon-128x128.png`) | 256×256 / 128×128 | Plugin-Icon |
| `banner-1544x500.png` (+ `banner-772x250.png`) | 1544×500 / 772×250 | Banner der Plugin-Seite |
| `screenshot-1.png` … | beliebig | Screenshots, Beschriftung unter `== Screenshots ==` in der readme.txt |

Diese README wird von der Deploy-Action nicht hochgeladen, nur Bilder.
